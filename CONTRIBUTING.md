# Contributing

1. Open an issue describing the bug or proposed change.
2. Create a branch for one focused change.
3. Run the game locally using the command in the README.
4. Check the behaviour affected by your change and describe what you verified.
5. Open a pull request with the problem, resulting behaviour, and validation.

For gameplay changes, check save compatibility, restart behaviour, and relevant ending requirements. For graphics changes, check movement, turning, fullscreen, object outlines, and mirror visibility. Respect reduced-motion preferences.

Do not commit credentials, personal information, local browser saves, or generated deployment archives. Keep script loading order intact until the shared global state is refactored.
