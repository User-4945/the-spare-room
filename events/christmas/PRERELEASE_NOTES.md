# The Spare Room v.3.5.0 — Christmas in Ashfield
Christmas Week 1 preview for the original game. Roblox uses a separate v.3.7.0 release.
Public Week 1 launch and Latest promotion: **11 December 2026, 20:00 GMT**.

The preview adds six secrets, three gated seasonal endings, three winter roles,
Santa-inspired anomalies, snow/squalls and a readable in-game clock.
Christmas sanity loss runs at 55% of the ordinary rate before class/weather modifiers.
Permanent story endings and existing save slots remain intact.

The downloadable web preview explicitly enables seasonal content for preview testing.
It does not enable the live Roblox event or replace GitHub's current Latest v.3.0.0.
This prerelease currently provides a browser ZIP and source ZIP, not new native installers.
